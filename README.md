# Moroccan English Teachers Community Platform

A comprehensive web platform designed specifically for Moroccan English teachers to share ideas, discuss teaching strategies, and build a professional community. Built with modern web technologies and featuring a clean, responsive design.

## 🎯 Project Overview

This platform serves as a dedicated space for Moroccan English teachers to:
- Share teaching experiences and best practices
- Discuss classroom challenges and solutions
- Exchange lesson plans and teaching materials
- Connect with colleagues across Morocco
- Access professional development resources
- Moderate content and maintain community standards

## 🚀 Key Features

### User System
- **Registration & Login**: Secure user authentication system
- **User Profiles**: Comprehensive profiles with teaching experience, school info, and bio
- **Role-based Access**: Regular teachers and administrators
- **Avatar System**: Auto-generated avatars from user initials

### Content Management
- **Post Creation**: Rich text posts with categories and grade levels
- **Comment System**: Nested comments with voting (upvote/downvote)
- **Content Categories**: Organized by teaching topics (Classroom Activities, Teaching Methods, etc.)
- **Search & Filter**: Advanced filtering by category, grade level, and search terms
- **Moderation Tools**: Admin controls for content management

### Community Features
- **Teacher Directory**: Browse and connect with other teachers
- **Categories Page**: Explore content by teaching topics
- **User Dashboard**: Personal statistics and activity
- **Admin Panel**: Comprehensive administration interface

### User Experience
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile
- **Modern UI**: Clean, professional design with smooth animations
- **Loading States**: Beautiful loading animations and skeleton screens
- **Notifications**: User-friendly notification system
- **Offline Support**: Basic offline functionality

## 🧪 Testing Instructions

### 1. Registration & Login
1. Click "Register" in the navigation bar
2. Fill in the registration form with sample data
3. Verify email validation and password requirements
4. Test login with demo accounts
5. Check "Remember me" functionality

### 2. Post Creation & Management
1. Log in with any demo account
2. Click "Create Post" button
3. Fill in title, content, category, and grade level
4. Submit and verify post appears in feed
5. Test editing and deleting your own posts

### 3. Comment System
1. Click on any post to view details
2. Add comments to posts
3. Test nested replies (click "Reply" on comments)
4. Use upvote/downvote buttons
5. Test comment moderation (admin accounts)

### 4. Search & Filter
1. Use the search bar to find specific content
2. Filter posts by category using the category buttons
3. Test combining search and filters
4. Verify results update in real-time

### 5. User Profiles
1. Click on any username to view their profile
2. Check profile statistics (posts count, join date)
3. Test editing your own profile
4. Browse the teachers directory

### 6. Admin Features
1. Log in with an admin account
2. Access the Admin Panel from user menu
3. View community statistics
4. Test post moderation tools
5. Check admin badges on posts/comments

### 7. Responsive Design
1. Test on mobile devices (iPhone, Android)
2. Check tablet layout (iPad, Android tablets)
3. Verify desktop experience
4. Test touch interactions on mobile
